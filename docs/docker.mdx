<h2 id="overview">Docker Deployment</h2>

Before starting, ensure you have completed the [Installation Prerequisites](/docs/installation), including forking the repository and setting up your GitHub App.

<h2 id="env-vars">Environment Variables</h2>

For Docker deployments, Codra reads configuration from a `.env.test` file (or your standard environment variables).

```bash
cp .env.test.example .env.test
```

Fill in the required GitHub credentials, `LLM_CONFIG_ENCRYPTION_KEY`, and set `APP_URL` to your domain or local tunnel. `DATABASE_URL` and `REDIS_URL` are already configured in the example file to point to the containers defined in the `docker-compose.yml`.

<h2 id="local-dev">Local Dev</h2>

Docker is the fastest path for local development. The included `docker-compose.yml` runs PostgreSQL, Redis, and the Codra worker together.

```bash
docker compose up
```

Use [ngrok](https://ngrok.com) or [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) to expose your local instance for GitHub webhook delivery.

<h2 id="build">Build Image</h2>

To build and run the image from source locally:

```bash
docker compose build
docker compose run --rm codra node packages/db/scripts/migrate.mjs
docker compose up -d codra
```

<h2 id="docker-hub">Docker Hub</h2>

To build, tag, and publish your own custom Codra image to Docker Hub:

```bash
docker build -f apps/node/Dockerfile \
  -t YOUR_DOCKERHUB_USER/codra:VERSION \
  -t YOUR_DOCKERHUB_USER/codra:latest .
docker push YOUR_DOCKERHUB_USER/codra:VERSION
docker push YOUR_DOCKERHUB_USER/codra:latest
```

<h2 id="run-published">Run Published Image</h2>

To run your published image (or an official one) via docker compose:

```bash
CODRA_IMAGE=docker.io/YOUR_DOCKERHUB_USER/codra:VERSION docker compose pull
CODRA_IMAGE=docker.io/YOUR_DOCKERHUB_USER/codra:VERSION docker compose run --rm codra node packages/db/scripts/migrate.mjs
CODRA_IMAGE=docker.io/YOUR_DOCKERHUB_USER/codra:VERSION docker compose up -d codra
```
